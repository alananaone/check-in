# 台灣少年權益與福利促進聯盟 (台少盟) - 實習生差勤打卡系統

專為「台灣少年權益與福利促進聯盟」（[youthrights.org.tw](https://www.youthrights.org.tw/)）實習生設計的高質感、極簡線條差勤打卡與時數管理系統。

支援公開部署於 **Vercel**，兼具本地零設定開發體驗與雲端 PostgreSQL 持久化儲存。

---

## 核心功能特色

1. **實習生身分切換**
   - 預載兩位實習生帳號：**王睿宏**、**林沁臻**。
   - 預設均為免密碼模式，可直接點選切換與打卡。
   - 兩位實習生皆可隨時自行設定個人密碼，或清空恢復為免密碼。

2. **秒級即時時鐘**
   - 顯示標準台北時間（UTC+8），包含公曆年月日、星期幾與跳動秒數。

3. **主動 GPS 地理定位與地址轉譯**
   - 進入頁面時主動徵求 HTML5 Geolocation 授權。
   - 自動透過逆地理編碼（Reverse Geocoding）將經緯度精準轉譯為台灣縣市、行政區與路名地址。
   - 支援手動微調地點與一鍵重新定位。

4. **上班簽到與下班簽退**
   - 狀態自動感應（上班中 / 未上班）。
   - 支援出勤備註填寫（如：辦公室、居家實習、外部會議或採訪）。
   - 送出打卡時同時寫入時間戳、類型、地理位置、座標與用戶來源 IP。

5. **每週實習累積時數統計**
   - 依據自然週（週一至週日）自動計算區段累計時數。
   - 當前正在上班中亦會即時計算進行中時數。
   - 線性進度條即時對照後台規範之每週目標時數與達成百分比。

6. **差勤管理後台 (`/admini` 或 `/admin`)**
   - 後台路徑為 `/admini`（`/admin` 自動轉址）。
   - 預設無密碼，點擊直接登入；可隨時設定或修改管理員密碼。
   - **實習時數規範**：自訂每週規定實習時數（以小時為單位，如 16 或 20 小時）。
   - **IP 安全限制**：預設為不限制（未來使用）。啟用後可設定允許打卡的 IP 白名單，未授權網路將被安全拒絕。
   - **打卡日誌審核**：完整日誌清單（時間、姓名、動作、地點、座標、IP、備註），支援依實習生篩選、異常紀錄刪除。
   - **CSV 報表匯出**：一鍵匯出含 UTF-8 BOM 之 CSV 檔案，可在 Excel 中無亂碼檢視與核算。

## 視覺與排版設計規範

- **色彩系統**：嚴格依據專屬色票演化：
  - `Ivory`：`#E1DAD3`
  - `Nude`：`#E4C9B6`
  - `Dusty Rose`：`#D7A49A`（下班簽退與警告）
  - `Sage`：`#9FA893`（上班簽到與成功）
  - `Baby Blue`：`#A4B1BA`（工時進度與輔助）
  - `Canvas Background`：`#FAF8F5`（溫潤暖米紙張底色）
  - `Ink Primary`：`#1F2526`（WCAG AAA 14:1+ 超高對比內文字）
  - `Line Structural`：`#E2DDD6`
- **極簡線條架構**：採用純線條劃分、報表表格與版面通欄，取代浮動陰影。
- **禁止使用 Card**：全站無任何卡片與外凸陰影容器，呈現典雅雜誌編排與無陰影平面層次。
- **絕對禁止 Emoji**：所有介面與標籤採用語意化幾何向量圖示 (Lucide SVG) 與純文字。
- **禁止 `border-left` 與 `border-top`**：嚴格貫徹邊框規則，僅使用全包圍邊框、底邊框 (`border-bottom`) 或底色。

## 本地開發運行

```bash
# 1. 安裝相依套件
npm install

# 2. 啟動本機開發伺服器
npm run dev
```

開啟瀏覽器前往 `http://localhost:3000` 即可使用打卡系統，或存取 `http://localhost:3000/admini` 進入後台。
本機未設定 PostgreSQL 時，系統會自動在 `./data/db.json` 建立檔案儲存，開箱即用。

## Vercel 公開部署指南

本專案已最佳化適配 Vercel Serverless 與 Edge 架構：

### 步驟 1：推送到 GitHub
本專案已連結至 GitHub 倉庫：
```bash
https://github.com/alananaone/check-in
```

### 步驟 2：在 Vercel 建立專案
1. 登入 [Vercel Dashboard](https://vercel.com/)。
2. 點擊 **Add New...** -> **Project**。
3. 匯入 `alananaone/check-in` 儲存庫。
4. Framework Preset 選擇 **Next.js**，點擊 **Deploy**。

### 步驟 3：綁定持久化資料庫（Vercel Postgres / Neon / Supabase）
由於 Vercel Serverless 為無狀態架構，建議在 Vercel 專案中綁定資料庫以獲得持久化資料：
1. 在 Vercel 專案儀表板點選 **Storage** 標籤頁。
2. 點擊 **Create Database** 並選擇 **Postgres** (Powered by Neon，免費額度充足)。
3. 點選 **Connect to Project**。
4. Vercel 會自動為專案注入環境變數 `POSTGRES_URL`。
5. 重新部署專案後，系統將在首次請求時**自動建構資料表**並預載實習生資料，完全無須手動執行 SQL 指令！
